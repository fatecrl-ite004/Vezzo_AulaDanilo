# Diagrama de classes

## Objetivo

O diagrama de classes é uma representação UML da estrutura estática do sistema. Ele organiza as classes, seus atributos, operações e os relacionamentos entre elas.

No contexto do Vezzo, o diagrama deve representar as principais estruturas de domínio relacionadas aos perfis de usuário, pacientes, profissionais, agendas, horários, consultas e lista de espera, conforme a implementação adotada pela equipe.

## Elementos que devem aparecer

- **Classe:** representa uma estrutura do sistema.
- **Atributos:** informações mantidas pela classe.
- **Métodos/operações:** comportamentos associados à classe.
- **Relacionamentos:** indicam como as classes se associam.
- **Multiplicidade:** indica quantas instâncias podem participar de uma relação.

## Observação

O diagrama de classes ainda precisa ser elaborado e validado pela equipe com base no código-fonte. Ele não deve ser tratado como equivalente ao MER: o MER representa a estrutura dos dados e suas relações no banco, enquanto o diagrama de classes representa a estrutura orientada a objetos do sistema.
